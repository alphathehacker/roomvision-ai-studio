# furniture-tools — Phase 2+ scope (NOT implemented in Phase 1)

This folder is a deliberate seam for the furniture / decor phase.

Planned scope (future):
- Furniture placement: pick items (sofa, table, lamp…) from a catalog and place,
  move, scale and rotate them on the room photo.
- Depth/occlusion handling so furniture sits believably behind/in front of surfaces.
- Object shadows and perspective matching.

Phase 1 intentionally shows **no** Furniture / Decor / Interior Styles buttons in the
UI — only the categories that actually work: Walls, Ceiling, Flooring, Lighting.
Do not add inert furniture buttons until the feature is real.
